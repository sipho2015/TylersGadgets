How to replace one

  1. Find the filename shown on its card.
  2. Overwrite that JPEG file with your own photo, or change the product's image and images paths in data/products.js.
  3. Remove the reference flags and source credit once you use your own photo. Confirm the listing's real details.
  4. Run npm.cmd test and npm.cmd run build, then redeploy.

This batch uses the named originals directly. You do not need to edit the old hashed files in assets/optimized/.
